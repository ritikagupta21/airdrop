Core Capabilities

Key Features of AirDrop-X

Engineered specifically for privacy, maximum bandwidth utilization, and simple connectivity.

Zero Server Storage

Files travel directly from Browser A to Browser B. The backend server only facilitates initial signaling and never touches your payload.

64 KB Chunk Streaming

Optimized 64 KB array buffer chunking with active backpressure detection (`bufferedAmountLow`) ensures stutter-free streaming and peak throughput.

6-Digit Room Pairing

Instant pairing system using dynamic 6-digit room codes generated on-demand without tedious user registrations or account creation.

DTLS & SRTP Encryption

All WebRTC DataChannel streams are natively protected using Datagram Transport Layer Security (DTLS) and Secure Real-time Transport Protocol.

Cross-Platform Web Standard

Works natively in standard modern web browsers on Windows, macOS, Linux, Android, and iOS without extra app downloads.

Unlimited File Size

Because data is streamed chunk-by-chunk directly between local device RAM buffers, files of any size can be transferred effortlessly.

Bank-Grade Privacy

Security & Privacy Assurance

Designed from the ground up around strict data minimization.

End-to-End Encryption

WebRTC enforces mandatory DTLS encryption for all data packets, preventing man-in-the-middle packet sniffing.

Ephemeral Room Sessioning

6-digit connection room codes auto-expire upon disconnection or transfer completion to prevent unauthorized access.

Zero Metadata Logging

File names, content, and transfer histories are never stored on any database or server log file.

Client-Side Memory Assembly

Files are reassembled directly in client RAM, ensuring immediate garbage collection upon download.

About AirDrop-X System

AirDrop-X was developed as a modern college project demonstration to illustrate high-performance browser-based peer-to-peer communication. By leveraging WebRTC's `RTCDataChannel` combined with WebSocket signaling, AirDrop-X solves the latency and privacy challenges associated with uploading large files to third-party cloud storage providers.

The platform operates completely peer-to-peer: once signaling connects two peers, data flows directly between device network interfaces over 64 KB memory chunks.

Project Title AirDrop-X – Secure P2P Web-Based File Transfer System
Protocol WebRTC DataChannel (SCTP over DTLS)
Signaling Mechanism Socket.io WebSockets
Chunk Resolution 64 KB (65,536 bytes) ArrayBuffer Slices
NAT Traversal Google Public STUN (stun:stun.l.google.com:19302)

Future Enhancements & Scope

  • Folder & Multi-File Batch Transfers: Native recursive zip streaming via JSZip.
  • Password Protected Transfers: AES-GCM 256-bit client-side key derivation prior to chunk slicing.
  • Multi-Peer Mesh Transfers: Simultaneous 1-to-N broadcasting across multiple connected peers.
  • Local Network Auto-Discovery: Automatic mDNS local Wi-Fi beaconing without manual room code entry.
