Core Capabilities

Key Features of AirDrop-X

Engineered for privacy, maximum bandwidth, and simple multi-device connectivity.

Zero Server Storage

Files travel directly Browser-to-Browser. The server only handles signaling, never your data.

64 KB Chunk Streaming

Optimized 64 KB chunks with backpressure detection ensures stutter-free streaming at peak throughput.

Multi-Device Sessions

One sender, multiple receivers. Share the same 6-digit code with as many devices as you need.

DTLS & SRTP Encryption

All WebRTC DataChannel streams are natively protected with DTLS and SRTP encryption.

Cross-Platform

Works in any modern browser on Windows, macOS, Linux, Android, and iOS — no app needed.

Unlimited File Size

Data is streamed chunk-by-chunk directly between RAM buffers — no size limits, ever.

Privacy First

Security & Privacy Assurance

Designed from the ground up around strict data minimization.

End-to-End Encryption

WebRTC enforces mandatory DTLS encryption preventing man-in-the-middle attacks.

Ephemeral Room Sessions

Room codes auto-expire on disconnect to prevent unauthorized access.

Zero Metadata Logging

File names, content, and transfer histories are never stored on any server.

Client-Side Assembly

Files are reassembled in your browser RAM with immediate garbage collection after download.

Academic Project Showcase

About AirDrop-X System

AirDrop-X was developed as a modern college project demonstrating high-performance browser-based peer-to-peer communication. By leveraging WebRTC's RTCDataChannel with WebSocket signaling, AirDrop-X solves the latency and privacy challenges of cloud file sharing.

Once signaling connects peers, data flows directly between devices over 64 KB memory chunks — no cloud, no middleman.

Project Title AirDrop-X – Secure P2P Web-Based File Transfer System
Protocol WebRTC DataChannel (SCTP over DTLS)
Signaling Socket.io WebSockets
Chunk Size 64 KB (65,536 bytes) ArrayBuffer
NAT Traversal Google Public STUN (stun:stun.l.google.com:19302)

Future Enhancements

  • Multi-File Batch Transfers: Native recursive zip streaming via JSZip.
  • Password Protected Transfers: AES-GCM 256-bit client-side encryption.
  • Multi-Peer Mesh: Simultaneous 1-to-N broadcasting.
  • Auto-Discovery: mDNS local Wi-Fi beaconing without room codes.
